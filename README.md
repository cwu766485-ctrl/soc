# SoC Peripheral UVM Verification

This repository combines two reusable digital IC verification projects for typical low-power IoT SoCs:

- `spim_uvm_tb/`: APB-programmed SPI master (SPIM) RTL and its SystemVerilog/UVM verification environment.
- `sramc_uvm_tb/`: AHB-based SRAM controller RTL and its SystemVerilog/UVM verification environment.

Each project directory contains its own source, verification environment, documentation, and scripts. See the project-level documentation for supported scenarios, setup instructions, and known verification scope.
